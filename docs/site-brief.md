## 部署

- 产物为纯静态文件，可放任意静态托管
- `codepulse.top` 暂不启用：其当前解析到腾讯云国内节点，且处于 DNSPod 未备案拦截状态
- 国内个人 ICP 备案不允许「经营销售」内容，故站内不出现接单、报价字样；若将来启用该域名，优先走香港/境外节点
- 托管平台实测（国内线路，2026-11-11，本机 curl）：
  | 平台 | 结果 |
  | --- | --- |
  | `*.github.io` | 200，TTFB 0.8s — 可用 |
  | `*.netlify.app` | 200，TTFB 1.3s — 可用 |
  | `*.pages.dev` | 10.8s 或直接超时 — 不可用 |
  | `*.vercel.app` | 超时 — 不可用 |
- 结论：**优先 GitHub Pages**（或 Netlify），不用 Cloudflare Pages / Vercel 默认域名
- 待办：需要本人登录 GitHub 才能创建仓库并开启 Pages；本机 `gh` 未登录、仓库无 remote
