03 / EK Lights（广东熠日科技） 2025.04 — 2026.10

海外电商自建站

一个面向全球客户的企业官网。运营要能自己改页面，用户要能在一秒内看到首屏，而第三方插件正在把这两件事一起毁掉。

角色
前端与自动化
技术栈
Shopify OS 2.0 · Liquid · Vue3 · Metafields · PageSpeed Insights

背景

专业舞台灯光品牌 EK Lights 的海外官网。它既要撑住一个全球品牌的形象——大画幅的产品摄影、克制的排版、多语言——又要保留完整的电商能力：产品线导航、商品详情、购物车与促销，一个都不能少。

问题

  1. 01 运营依赖研发。EK 的产品线有 MC、EC、K 系列等多条，改一句文案、换一张图、上下架一款灯，都要排进研发的迭代里。
  2. 02 首屏 4 秒以上。第三方 App 各自注入脚本和样式，加上未压缩的图片，用户在看到内容之前就流失了。
  3. 03 购物链路割裂。原生的跳页式购物车打断了浏览，加购转化率一直上不去。

做法

01

让运营自己拖页面

基于 Liquid 深度二开主题，编写自定义 JSON Schema 并绑定 Metafields，把商品详情页与大促落地页拆成可拖拽配置的模块。运营在后台拼页面，研发不再出现在这条路径上。

02

重做购物链路

用 Shopify Ajax API 重构为无刷新抽屉式购物车，并定制阶梯满减进度条与组合捆绑加购组件。用户加购时不离开当前页，满减门槛直观可见。

03

把第三方脚本关进笼子

用 defer / async 延迟加载非关键脚本，清理 App 卸载后残留的代码与样式，图片全部懒加载并转现代格式，最后对照 Google PageSpeed Insights 逐项压 LCP。首屏从 4 秒以上降到 1.9 秒以内。

04

高频运营操作交给脚本

多语言文案同步、批量上下架、素材归档这些每天重复的动作，用 Python 与影刀 RPA 写成浏览器自动化，日常运营配置效率提升 80% 以上。
